2. 流程目标

新人考核与培训规定新入职销售从入职起的考核与培训全流程。新人前期考核要求入职 15 天内完成有效商机报备（硬性指标），由区域销售负责人督导。提前转正属奖励性质：申请提前转正须同时满足业绩门槛与业务认证门槛（双门槛），任一未达标不予提前转正、不影响按期转正；获批者即为正式员工，自下一考核周期起纳入正式销售考核（KPI 由区域销售负责人分配下达）。培训与认证为销售线全员适用，重点考核事业部组织的产品线专业培训与业务认证，讲师由内部架构师等业务骨干担任。全部考核项自入职起纳入 CRM 追踪。

3. 输入输出

项目内容
触发条件新入职销售入职报到
上游流程无（入职为起点）
下游流程转正后进入常规考核体系（5.2/5.3）；商机采集/报备（flow-01-1）→ 新人 15 天内须完成有效商机报备
产出物新人考核记录、有效商机报备记录、培训记录（内容/结果/讲师确认）、认证考试记录、提前转正申请与审批记录
关键字段入职日期、报备时间、有效商机判定、培训内容、考核结果、讲师确认、认证考试结果、转正审批、业绩门槛达标状态、认证门槛达标状态

4. 详细步骤

4a. 新人前期考核

环节规定
15 天硬指标新入职销售入职 15 天内须完成有效商机报备（硬性指标，有效商机判定见 3.7），由区域销售负责人负责督导与考核
入职前半月考核按非标机制执行，由区域销售负责人负责（导师带教与情景演练），考核结果留痕
转正前月度考核每月底进行考核，内容为基础业务与情景演练；考核未达标的追责其导师或本人
转正面谈转正前考核维度与转正面谈按《试用期员工管理办法》执行，本条为销售线考核内容

4b. 转正双门槛

门槛标准
业绩门槛按《试用期员工管理办法》与销售线考核执行
业务认证门槛按所负责产品线要求（AWS 业务线须通过对应业务的 AWS 从业者/专业认证考试）
双门槛关系两项均达标方可提前转正；任一未达标不予提前转正，不影响按期转正（按《试用期员工管理办法》执行）
性质与后果提前转正属奖励性质（V13 §5.7）：获批即正式员工、无需另行转正考核；KPI 自生效起的下一考核周期由区域销售负责人分配下达

4c. 培训与认证（全员适用）

环节规定
通用培训公司统一组织（人力资源部安排），不作为销售业务线考核重点
专业培训事业部组织的产品线专业培训与业务认证，为销售线重点考核内容
讲师由内部架构师等业务骨干担任
记录培训内容、考核结果、讲师确认自入职起记录；CRM 上线后系统追踪留痕，上线前以线下记录留痕（记录责任：运营组）

4d. 泳道步骤（RACI）

步骤 新人销售 区域销售负责人 导师 运营组
1.1 入职报到，启动 CRM 追踪 I I — C
1.2 入职前半月：导师带教+情景演练（非标机制） C A C —
1.3 15 天内完成有效商机报备（硬性指标） C A — —
1.4 转正前月度考核（基础业务+情景演练） C A I —
1.5 产品线专业培训+业务认证考试 C I — C
1.6 本人申请提前转正→双门槛判定（业绩+认证） C A — C
1.7 双门槛达标→可以提前转正（KPI 自下一考核周期分配下达） I A — C
1.8 任一未达标→不予提前转正（不影响按期转正） I A — C

R=决策 A=审批 C=执行 I=知会

6. 边界与断点

环节处理方式说明
转正面谈按《试用期员工管理办法》转正前考核维度与转正面谈按《试用期员工管理办法》执行，本条为销售线考核内容
通用培训非考核重点公司统一组织的人力资源部培训不作为销售业务线考核重点
CRM 追踪上线前后差异CRM 上线后由系统追踪留痕；上线前以线下记录留痕（记录责任：运营组）
必须留痕节点系统/线下留痕入职日期、报备记录、月度考核结果、培训内容与结果、讲师确认、认证考试结果、转正审批均须留痕

7. 异常分支

  • 15 天内未完成有效商机报备：硬性指标未达标，由区域销售负责人负责督导与考核，追责本人。
  • 转正前月度考核未达标：追责其导师或本人。
  • 业绩达标但认证未通过：不予提前转正（双门槛须同时满足），不影响按期转正。
  • 认证通过但业绩未达标：不予提前转正（双门槛须同时满足），不影响按期转正。
  • 提前转正申请：须同时满足双门槛，任一未达标不予提前转正（不影响按期转正）。

8. 关键控制点

类型控制点动作/后果

可核查提前转正双门槛业绩门槛+业务认证门槛须同时达标方可提前转正；未达标不予提前转正，不影响按期转正

可核查月度考核转正前每月底考核（基础业务+情景演练），未达标追责导师或本人
