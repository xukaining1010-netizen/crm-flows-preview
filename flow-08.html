2. 流程目标

商机追踪与看板贯穿商机生命周期全流程，以七段阶段模型（线索→商机→方案→测试→合同→服务中→关闭/公海）管理推进进度。核心机制为三条独立触发规则——商机有效期（3 个月）、6 周预警（无实质进展）、3 周自动关闭（无进度更新），任一先触发即进入对应处理，互不等待。商机看板按区域（华北/华东/华南-广州/华南-深圳）与业务线分组输出，以红黄绿停留标志提示进度，替代文字化 Excel 周报汇报。

3. 输入输出

项目内容
触发条件商机报备后进入追踪周期，开始 3 个月有效期计时
上游流程商机采集/报备（flow-01-1）→ 报备后进入追踪；线索管理/资格判定（flow-07）→ 合格线索转商机后进入追踪
下游流程6 周预警→面谈督导→关闭/公海（flow-02）；3 个月到期→延期审批或关闭；3 周无更新→自动关闭→公海
产出物商机阶段状态记录、预警记录、自动关闭记录、商机看板（按区域+业务线分组）
关键字段商机阶段、报备日期、有效期到期日、最后进度更新时间、预警状态、看板停留标志（红/黄/绿）

4. 详细步骤

4a. 七段阶段模型

阶段说明
线索有初步意向但未满足转商机条件，停留本阶段，不计入商机有效期
商机已确认客户基本情况与初步需求，进入跟进流程的有效商机
方案可选环节：需方案设计/定制报价/多产品组合时方须完成；标准产品、加单、续签可跳过
测试进入测试与售前支持阶段（见 3.4 / flow-11）
合同进入合同审核与审批阶段（见 3.5 / flow-13）
服务中合同审批通过、服务已开通的在服商机（见 3.6）
关闭/公海已关闭或进入公海的商机（见 3.8 / flow-02）

4b. 三条独立触发规则（互不等待）

规则触发条件处理
商机有效期自报备之日起满 3 个月可申请延长（事业部/业务线负责人审批）；未申请或未获批且无实质推进→按 3.8 关闭处理
6 周预警自报备起满 6 周无实质进展（无方案/测试/合同动作）系统提醒（上线前人工）→ 销售负责人面谈督导 → 持续无果→关闭与公海规则处理
3 周自动关闭连续 3 周无进度更新关闭前 3 个工作日提醒销售→自动标记关闭→进入公海

4c. 泳道步骤（RACI）

步骤 销售 数据运营 业务线负责人
1.1 商机报备后进入追踪，启动 3 个月有效期计时 C I —
1.2 商机阶段推进（方案→测试→合同→服务中） C I —
1.3 6 周预警触发（系统/人工提醒） I C —
1.4 预警后销售负责人面谈督导 C — A
1.5 连续 3 周无进度→自动关闭（关闭前 3 日提醒） I C —
1.6 3 个月到期→申请延长有效期 C I A
1.7 未延期且无实质推进→关闭处理 I C —
1.8 有效商机判定（必填字段齐全/公海领取/仅跟进计入考核） I C A
1.9 看板输出（按区域+业务线分组，红黄绿标志） I C —

R=决策 A=审批 C=执行 I=知会

6. 边界与断点

环节处理方式说明
有效期与自动关闭的关系独立触发3 个月有效期与 3 周无进度自动关闭为两条独立规则，任一先触发即处理，互不等待
方案阶段可选环节标准产品、加单、续签等无需方案设计的，可直接进入测试或合同
CRM 上线前后差异人工→系统上线前由数据运营依据商机台账人工核算与提醒；上线后由系统自动执行
看板范围内地业务看板为内地业务看板，港新业务不纳入
例外监控单独监控未报备但已测试/计费、原厂 CIO 背书、京东渠道等特殊来源单独监控
必须留痕节点系统留痕报备时间、有效期到期日、预警记录、自动关闭记录、延期审批、阶段变更均须留痕

7. 异常分支

  • 6 周预警后仍无进展：面谈督导后持续无果的，按关闭与公海规则处理（见 3.8 / flow-02）。
  • 有效期到期未申请延期：视为放弃，按 3.8 关闭处理。
  • 3 周自动关闭但商机仍在实质推进：如处于测试阶段但 3 周未更新进度，可申请延长有效期，审批后继续推进。
  • 特殊来源商机：未报备但已在测试或计费中的客户、原厂 CIO 背书客户、京东渠道等，单独监控，不适用常规追踪规则【待 V13 定稿确认】。
  • 有效商机判定争议：以必填字段齐全（姓名/联系方式/职位/公司/需求/预算，缺一不可）为准；公海领取一律视为有效。

8. 关键控制点

类型控制点动作/后果
可核查三条独立触发规则互不等待有效期、6 周预警、3 周自动关闭任一先触发即进入对应处理
可核查6 周预警 + 面谈督导满 6 周无实质进展触发系统提醒，面谈督导后仍无果→关闭
可核查有效商机判定标准必填字段齐全即有效；公海领取视为有效；仅「跟进」状态计入有效商机考核
可核查看板按区域+业务线分组红黄绿停留标志替代 Excel 周报，按华北/华东/华南-广州/华南-深圳+业务线分组
可核查延期审批延长须经事业部/业务线负责人审批，期限与次数由审批人按实际推进情况确定
