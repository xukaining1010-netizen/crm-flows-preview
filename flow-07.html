2. 流程目标

线索管理是商机生命周期的最前置环节。有初步意向但未满足转商机条件的客户记录停留在线索阶段，不计入商机，不占用商机有效期计时。销售须通过首次客户沟通、确认客户基本情况与初步需求、获得客户明确推进意向后，方可将线索转为商机并进入报备流程。本流程定义线索阶段的判定标准、转商机的 4 项条件（须同时满足）以及线索池管理规则。

3. 输入输出

项目内容
触发条件销售获取新客户意向信息（自拓/原厂介绍/内部介绍/市场活动线索）
上游流程市场活动线索归集（flow-10）→ 分配后的线索；公海线索池 → 认领的线索
下游流程商机采集/报备（flow-01-1）→ 合格线索转为商机进入报备流程
产出物线索记录、资格判定结果（合格/不合格）、转商机记录或线索池留存
关键字段客户名称、官网、联系人、所在行业、拟采购产品方向、预算量级（MRR）、预计时间、沟通记录、推进意向标记、线索来源

4. 详细步骤（泳道表 · RACI）

4a. 转商机 4 项条件（须同时满足）

序号条件说明
1已完成首次客户沟通面谈或线上会议均可，并留存沟通记录
2已确认客户基本情况客户名称、官网、联系人、所在行业
3已确认初步需求拟采购的产品方向、预算量级（MRR）、预计时间
4客户明确表示可继续推进客户有明确的推进意愿

4b. 泳道步骤

步骤 销售 运营组
1.1 线索录入（来源标记：自拓/原厂介绍/内部介绍/市场活动） C —
1.2 首次客户沟通（面谈/线上会议）+ 留存记录 C —
1.3 确认客户基本情况（名称/官网/联系人/行业） C —
1.4 确认初步需求（产品方向/预算MRR/预计时间） C —
1.5 客户明确推进意向 C —
1.6 资格判定（4 项条件同时满足?） C A
1.7 合格 → 转商机，进入报备流程 C I
1.8 不合格 → 留存线索池，不计入商机 — C

R=决策 A=审批 C=执行 I=知会

6. 边界与断点

环节处理方式说明
线索来源标记CRM 内标记自拓 PIO / 原厂介绍 / 内部介绍 / 市场活动线索，须标记来源以追溯
线索池管理CRM 内闭环未满足转商机条件的线索留存线索池；公海线索池与公海商机池为独立机制
线索不计入商机有效期系统规则线索阶段不触发商机有效期（3 个月）计时，转商机后才开始
CRM 上线前台账执行人工执行线索录入与资格判定由数据运营依据线索台账人工执行
必须留痕节点系统留痕线索录入时间、沟通记录、资格判定结果、转商机时间均须留痕

7. 异常分支

  • 已约见但客户未明确意向：仍为线索，不计入商机，不占用商机有效期计时。
  • 4 项条件部分满足：任一条件不满足则不能转商机，留存线索池继续培育。
  • 沟通记录未留存：视为条件 1 未满足，不得转商机。
  • 从公海线索池认领：认领后须重新走资格判定，合格后转商机并报备。
  • 市场活动线索逾期未录入：超过活动结束后 3 个工作日未录入的，该线索不计入该销售业绩归属候选。
  • 分配后 5 工作日未跟进：线索释放回公海线索池（与 3.8 公海规则衔接）。

8. 关键控制点

类型控制点动作/后果
可核查4 项条件同时满足缺一不可，任一不满足不得转商机
可核查首次沟通记录留存面谈或线上会议均可，须留存沟通记录作为条件 1 凭证
可核查线索不计入商机有效期线索阶段不触发 3 个月有效期计时，转商机后才开始
可核查线索来源标记须标记来源（自拓/原厂介绍/内部介绍/市场活动）以追溯
可核查从公海领取的商机视为有效商机从公海领取的商机一律视为有效商机，无需重新走资格判定
