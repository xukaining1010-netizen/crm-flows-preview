2. 流程目标

撞单/归属争议裁决处理同一商机被两名及以上销售报备的归属冲突。判定依据以报备或首次登记时间先后为第一顺位；时间相同以客户书面指定为准；以上均无由区域销售负责人或业务线负责人裁定。判定结果须在台账或 CRM 中留痕。

3. 输入输出

项目内容
触发条件同一条商机被两人报备或提交（构成撞单）
上游流程商机采集/报备（flow-01-1）→ 发现重复报备
下游流程归属确定 → 更新主销售记录；业绩归属变更（flow-09）
产出物归属裁决记录、主销售确认、留痕记录
关键字段报备时间/首次登记时间、客户书面指定凭证、裁决人、裁决结果

4. 详细步骤（泳道表 · RACI）

步骤 销售（双方） 运营组 区域/业务线负责人
1.1 撞单识别（系统/人工发现重复报备） I C —
1.2 第一顺位判定：报备/首次登记时间先后 — C A
1.3 时间相同 → 客户书面指定 C C A
1.4 以上均无 → 负责人裁定 — I A
1.5 裁决结果留痕（台账/CRM） — C A
1.6 更新主销售，通知双方 I C —

R=决策 A=审批 C=执行 I=知会

6. 边界与断点

环节处理方式说明
判定主体限制CRM 内执行仅限区域销售负责人或业务线负责人判定
必须留痕节点系统留痕裁决结果须在台账或 CRM 中留痕，含判定依据与裁决人
客户指定凭证书面/可留痕确认口头指定不予认定

7. 异常分支

  • 时间相同或无法区分：以客户书面指定的对接人为准。
  • 以上均无：由区域销售负责人或业务线负责人裁定。
  • 虚构客户指定争夺商机：按 6.1 红线处理。
  • 客户指定仅落在项目级：不决定客户整体归属（见 flow-06）。
  • 同一客户不同项目：不视为撞单，各项目业绩归各自主销售（见 flow-15）。

8. 关键控制点

类型控制点动作/后果
