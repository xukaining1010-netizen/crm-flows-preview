2. 流程目标

报备失效处理解决因原厂侧变动导致已报备商机无法继续推进的处置问题。失效情形包括原厂指定其他经销商承接同一客户、原厂直销团队直接下场、原厂对接人或政策变更等。核心目标：及时认定失效、核定原报备销售投入、保留一定期限内优先归属，并强制 3 个工作日内上报，防止隐瞒不报导致资源浪费与商机真空。

3. 输入输出

项目内容
触发条件销售知悉原厂侧发生失效情形（原厂指定其他经销商 / 原厂直销下场 / 原厂对接人或政策变更）
上游流程商机采集/报备（flow-01-1）→ 已报备商机受原厂变动影响；跟进处理（flow-01-3）→ 测试/合同推进中发现原厂变动
下游流程投入核定 → 优先归属保留或释放；商机状态更新为「失效」；如释放则可能进入公海（flow-02）
产出物失效认定记录、投入核定结论、优先归属保留期限（如有）、上报时间戳
关键字段失效情形类型、知悉时间、上报时间、投入核定金额/资源、优先归属保留期限、业务线负责人审批记录

4. 详细步骤（泳道表 · RACI）

步骤 销售 运营组 业务线负责人
1.1 知悉失效情形（原厂指定其他经销商 / 直销下场 / 政策变更） C I —
1.2 3 个工作日内上报运营（不得隐瞒） C A —
1.3 失效情形核实与认定 — C A

R=决策 A=审批 C=执行 I=知会

环节处理方式说明

7. 异常分支

  • 销售隐瞒不报：知悉失效后超过 3 个工作日未上报的，按 6.1 红线违规处理。
  • 失效情形无法明确核实：运营与业务线负责人共同判断，存疑时按保守处理（暂标记「待核实」，暂停推进）。
  • 原厂政策变更影响多个商机：批量处理，逐个认定并留痕；业务线负责人统一核定投入。
  • 投入核定后不保留优先归属：商机释放，可能进入公海流转（见 flow-02）。
  • 失效后原厂恢复合作可能：保留优先归属期限内可重新报备推进；超期按新商机处理。

8. 关键控制点

类型控制点动作/后果
红线知悉失效后隐瞒不报超过 3 个工作日未上报按 6.1 红线违规处理
可核查上报时限（3 个工作日）销售须在知悉后 3 个工作日内上报运营
可核查投入核定留痕业务线负责人核定投入并留痕，作为优先归属保留依据
可核查失效认定与状态更新失效情形经核实认定后，商机状态更新为「失效」并留痕
