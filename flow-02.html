2. 流程目标

公海流转是签约后的回收-再分配独立闭环。测试最终不通过的商机关闭满 3 个月后自动进入公海，可被任意销售认领。认领前须核验原厂保护期状态，防止内部已放公海但原厂判撞单。离职触发释放无推进商机进入公海。

3. 输入输出

项目内容
触发条件商机关闭满 3 个月且未被原销售重新激活；或销售离职触发释放
上游流程跟进处理（flow-01-3）→ 测试不通过关闭；离职交接（flow-16）
下游流程商机采集（flow-01-1）→ 认领后重新走报备流程
产出物公海商机记录、认领记录、原厂保护期核验结果
关键字段关闭时间、关闭结果归因、原销售、公海进入时间、认领人、认领时间

4. 详细步骤（泳道表 · RACI）

步骤 销售 运营组 数据组
1.1 商机关闭（手动/自动）+ 结果归因 C A —
1.2 关闭满 3 个月，未被重新激活 — — A
1.3 进入公海前：原厂保护期核验 — A —
1.4 进入公海，可被任意销售认领 I — C
1.5 认领 + 重新走报备流程 C A —
1.6 原销售 3 个月内可重新激活 C I —

R=决策 A=审批 C=执行 I=知会

7. 异常分支

  • 原厂保护期未届满：不进入公海流转，防止新销售重新报备被原厂判撞单。
  • 原销售 3 个月内重新激活：须重新走商机报备流程。
  • 离职触发：已认领但无推进进度的商机全部进入公海；已交接的不受影响。
  • 单次测试 NO 未形成最终结论：不进入关闭流程，也不进入公海。
  • 重点商机关闭：须附结果归因（成/败+主因），重大商机附一句话复盘。
